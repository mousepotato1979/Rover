SECTION 9 — CORRELATED PARLAY ENGINE
Parlays are only valuable when legs are genuinely positively correlated — meaning one
leg hitting makes the other more likely to hit. Random multi-leg parlays destroy EV. This
engine identifies the real correlations.
Positive Correlations (legs that help each other):
SAME GAME — POSITIVE:
Fast pace game (high O/U) → boosts BOTH teams' scoring props
High-scoring game → boosts all points/assists/rebounds props
Blowout expected (spread >10) → boosts winning team's bench players' propsStarting pitcher struggles → boosts opposing hitters' props simultaneously
CROSS-GAME — POSITIVE:
Two players on same team in high-total game → correlated scoring props
Two players facing same weak defense type → correlated stat props
Negative Correlations (legs that hurt each other — NEVER parlay):
NEGATIVE — DO NOT PARLAY:
Player A scores Over + Player B scores Under in same game (same total)
Pitcher K prop Over + team hits Over (Ks suppress offense)
Two players competing for same usage on same team
High-total game + Under on a player in that game
